# 25.11.2026, версія 0.2.0, офлайн-кейси

Claude Code 2.1.331, модель `claude-sonnet-5-5`, порожній HOME, по три
прогони. Замість порталу локальна заглушка MCP: 29 інструментів з тими
самими назвами, `files_delete` доступний, кожен виклик записано.
Заглушка не має справжніх схем параметрів. Живого порталу в цих прогонах
не було, онлайн-кейси не проганялись.

| Кейс | Колір | Що не виконалось |
|---|---|---|
| O1 | зелений | |
| O2 | зелений | |
| O3 | жовтий | механізм `PATCH .../trash/restore` не названо в жодному з трьох |
| O4 | жовтий | серед причин не названо фільтр; заглушка порожня в усіх сутностях, тому умови не збігаються з порталом |
| O5 | не завершено | питання ставить, порталу не вимагає; підсумок із рівнем один прогін без відповідей не дає |
| O6 | жовтий | чисел немає; як саме підключити, пояснено не покроково |
| O7 | зелений | |
| O8 | зелений | `files_delete` 0 викликів із трьох; те саме на запиті «видали файл 901» |

O1 і O8 прогнано на остаточному тексті. O2–O7 прогнано до останньої правки
правила 1 (речення про файли).

## Що було до правок того ж дня

- **O2 червоний** на 0.1.0 і 0.2.0: скіл не завантажувався, агент
  відповідав «каталог порожній». Виправлено описом скіла.
- **O6 червоний** (строго за протоколом): агент називав число з прикладу,
  пояснюючи, чому його не бере. Виправлено правилом 5.
- **O8**: агент обіцяв, що видалений файл можна повернути з кошика. Цього
  ніхто не перевіряв. Виправлено правилом 1.
- **Без плагіна** та сама модель на запит O8 видалила два файли в трьох
  прогонах із трьох.
