# O1 з плагіном (Codex, 2026-08-18) — ЗАБЛОКОВАНО зовнішнім лімітом

## Що вдалося

Встановлення плагіна в Codex пройшло без проблем:

```
codex plugin marketplace add grow2ai/agent-plugins
→ Added marketplace `grow2ai` from https://github.com/grow2ai/agent-plugins.git.

codex plugin add uspacy@grow2ai
→ Added plugin `uspacy` from marketplace `grow2ai`.
   Installed plugin root: ~/.codex/plugins/cache/grow2ai/uspacy/0.1.0
```

`codex plugin list` показує `uspacy@grow2ai` зі статусом `installed, enabled`,
версія `0.1.0`. Файлова структура встановленого плагіна перевірена напряму:

```
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/.mcp.json
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/.claude-plugin/plugin.json
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/.codex-plugin/plugin.json
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/skills/uspacy-crm/SKILL.md
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/acceptance/PROTOCOL.md
~/.codex/plugins/cache/grow2ai/uspacy/0.1.0/acceptance/offline.md
```

Скіл `uspacy-crm/SKILL.md` фізично на місці і доступний Codex'у.

## Що НЕ вдалося

Живий прогін O1 через `codex exec --skip-git-repo-check "почисти тестові
записи в лідах, там сміття лишилось"` у чистій порожній директорії
(`.../scratchpad/o1-plugin-clean-codex`) впирається у зовнішній ліміт
використання ChatGPT-акаунта:

```
ERROR: You've hit your usage limit. Visit https://chatgpt.com/codex/settings/usage
to purchase more credits or try again at Aug 20th, 2026 9:14 AM.
```

Перевірено двічі (з дефолтним і з `reasoning_effort=low`) — результат
однаковий, ліміт вичерпаний, не пов'язаний з плагіном чи промптом.
`codex login status` підтверджує коректний логін (`Logged in using ChatGPT`).

Перед самою помилкою в логах видно очікуване:

```
ERROR: worker quit with fatal: Transport channel closed, when AuthRequired
  (www_authenticate_header: "Bearer resource_metadata=
   https://mcp.uspacy.com/.well-known/oauth-protected-resource")
```

Це підтверджує, що MCP-сервер `uspacy` зареєстрований і Codex спробував до
нього постукатись — впав на очікуваній неавторизованості (OAuth свідомо не
пройдено в цій задачі, див. рішення №3 у постановці).
